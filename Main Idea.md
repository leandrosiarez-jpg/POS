# Un sistema inteligente no se construye programando conductas, sino diseñando un universo donde las conductas útiles emerjan, se adapten y evolucionen.

## Un sujeto tiene autonomia porque este la necesita para perdurar en el tiempo si es que el entorno fuerza esta conducta.

## El entorno debe ser el encargado de poner a prueba a los sujetos, siendo el filtro de la supervivencia o reproducción

## Para lograr que el entorno se ocupe de filtrar sujetos se deben implementar leyes universales en un entorno de máxima jerarquía. 

## El tiempo y un factor de entropia por tiempo, leyes de espacio acordes a principios algebráicos.

## El sujeto debe emerger, hay que encontrar distintas configuraciones para permitir la emergencia


Regla de la POS: Los sujetos nunca interactúan directamente entre sí. Solo interactúan con el Entorno.
